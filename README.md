# AI PRD

AI PRD transforms ideas into production-ready Product Requirements Documents with a Next.js, Tailwind, Prisma, Supabase, OpenAI, Stripe, and shadcn-style foundation.

## Quick Start

```bash
npm install
npm run db:push
npm run dev
```

Configure `.env.local` before using Supabase Auth, OpenAI, Stripe, or PostgreSQL.
